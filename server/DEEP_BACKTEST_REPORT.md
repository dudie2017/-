## 五、最终生产建议

1. **只把三重筛选通过的品种纳入核心底仓**，其余品种需真 walk-forward 验证后再定。
2. **噪声参数固定**：trendFilter、edgeLookback 可固定为最优取值，缩小下次寻优搜索空间。
3. **directionMode 是最敏感参数**，需分牛/熊/震荡市验证，避免把"趋势 beta"误当 alpha。
4. **下一步**：对通过三重筛选的品种做真 walk-forward（前段寻优 → 后段验证），用 `STORE_TRADES=1` 重跑存 trades。
