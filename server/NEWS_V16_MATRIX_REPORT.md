## 核心结论

### 1. 冲击后冷却过滤：无增益（负优化）
- S1(5日)/S2(10日)/S3(20日) 回报 8906-9386%，均低于基准 S0(9515%)
- 仅 S4/S5（只躲大雷/极端雷）接近基准
- 解读：冲击日附近常是顺势行情，机械"冷却回避"反而错过盈利

### 2. 共振加仓：显著增益（最优方案）
- S6（冷却+共振时仓位x1.3）：**10421%，较基准 +9.5%**
- 解读：新闻面与技术面共振时增强信心有量化支撑

### 3. 背离降仓：严重负优化
- S7（背离时仓位x0.5）：**7696%，较基准 -19%**
- 解读：V16 技术方向本身有效，新闻背离不足以推翻，降仓错失大行情

### 4. 冲击时平仓：负优化
- S9（含冲击平仓）：8085% 且回撤升至 10%，明显恶化
- 解读：冲击日平仓在剧烈行情中断仓，错失后续修复行情

### 5. 回撤控制最优
- S10（只躲大雷+增强+平仓）：回撤最低 **5.0%**（基准 6.0%）
- 但回报 8815% 低于 S6，回撤与回报需权衡

### 6. 事件库驱动夏普最优
- S12（真实事件驱动冷却）：夏普 **4.19** 全矩阵最高，回报 9287% 接近基准
- 解读：真实事件过滤比价格冲击代理更精准
