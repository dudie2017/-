# 持仓快捷操作 + 首页持仓看板

## 概述

将现有的"交易日志（Journal）开仓/平仓"流程简化为一键式操作：在首页雷达直接点品种开仓、首页持仓卡片直接平仓，开平仓自动同步创建复盘记录。核心目标是把分散在三处（雷达→交易日志→持仓页→复盘页）的操作压缩到首页完成。

## 技术方案

| 维度 | 选择 | 理由 |
|------|------|------|
| 数据源统一 | Journal 的 Supabase `manual_trades` 表为唯一持仓来源 | 现有两套持仓（Journal/Supabase + Positions/AsyncStorage）已造成数据分裂，应统一 |
| 开仓入口 | 首页品种卡片长按 / 点击右侧操作按钮 → 底部弹出开仓面板 | 不跳页、不打断浏览流 |
| 平仓入口 | 首页持仓卡片点击 → 弹出平仓确认面板 | 不跳页 |
| 复盘同步 | 开仓/平仓时自动调用 `POST /reviews/:date/varieties` | 无需用户手动去复盘页登记 |
| 合约选择 | 开仓面板顶部合约选择器，默认主力可切换 | 同一品种不同合约价差小但价格不同，分析用主力、价格用实选合约 |
| 旧持仓页 | 保留但标记为"传统模式"，首页看板优先展示 Journal 数据 | 平滑过渡，不破坏已有功能 |

## 功能模块

### 1. 首页持仓看板（radar 页面新增）

- **位置**：扫描概览条下方、品种列表上方，作为可折叠区块
- **数据源**：`fetchTrades(status='open')` 获取所有未平仓记录
- **卡片展示**：合约编号 | 品种名 | 多/空标签 | 入场价 → 现价 | 浮盈亏额+百分比 | 止损/目标线
- **空态**：无持仓时折叠隐藏，有持仓时自动展开
- **实时价格**：从已有的 `fetchMarketSummary` 返回的 `VarietyItem[]` 中匹配现价

### 2. 快捷开仓面板（首页内底部弹窗）

- **触发**：品种卡片右侧新增"+"操作按钮，点击弹出开仓 Bottom Sheet
- **合约选择**：顶部合约选择器，默认主力合约，可切换至同品种其他合约（如 EB2508、EB2509）
- **切换合约行为**：非主力合约时，按需拉取该合约最新 K 线数据（仅价格字段：现价/昨结），分析维度（P/Gate4/Edge/key_levels）沿用主力合约结论
  - 理由：同一品种不同合约价差通常在 1-3%，趋势方向和 Gate4 维度（AI 方向、趋势健康度、量仓）与主力高度一致，无需全量重跑扫描
- **预填字段**：品种代码/合约编号、方向（默认信号方向）、入场价（默认所选合约现价）、止损（默认主力合约 key_levels 按价差偏移后填入）、目标（同上）、手数（默认 1）
- **手动调整**：所有字段可编辑
- **提交**：调 `createTrade()`，存入合约编号，成功后刷新持仓列表 + toast 提示

### 3. 快捷平仓确认（首页内弹窗）

- **触发**：点击持仓卡片 → 弹出平仓确认面板
- **展示**：品种、方向、入场价、现价、预估盈亏额+百分比
- **平仓价**：默认现价，可手动修改
- **提交**：调 `closeTrade()`，成功后刷新持仓列表 + 自动创建复盘记录

### 4. 复盘自动同步

- **开仓时**：自动创建品种复盘记录（variety_reviews），记录信号等级、AI 方向、市场状态等（从扫描数据获取）
- **平仓时**：更新品种复盘记录，写入平仓理由（默认"信号平仓"）、盈亏结果
- **实现**：Journal screen 已有 `handleSave` 调用复盘 API 的先例，首页面板复用同一后端接口

### 5. 后端补充

- 新增 `GET /api/v1/trading/contracts/:code` — 列出某品种可交易合约列表（调用现有 `detectMainContract` 中候选合约扫描逻辑，返回 contract + 最新价 + 昨结）
- 新增 `GET /api/v1/trading/contracts/:code/:contract` — 获取指定合约的最新 K 线（仅返回最近 2-3 根用于价格展示，不跑全量分析）
- 现有 `/api/v1/trading/manual` 和 `/api/v1/trading/reviews` 已完整，`manual_trades` 表已有 `contract` 字段可存合约编号

### 全局导航

> type: stack
> platform: mobile

无 Tab Bar 变更。首页（`/`）保留 Stack 导航，持仓看板和开平仓面板均为首页内嵌组件，不新增独立页面。

### 页面详情

##### @page(/) Brooks Radar 首页（改造）

**核心职责**：品种扫描概览 + 持仓看板 + 快捷开平仓入口。

**布局**：

```
┌──────────────────┐
│ 导航栏：BRK Radar + 刷新按钮      │
├──────────────────┤
│ 持仓看板（有持仓时展开）          │
│  [EB0 多 8331→8300 浮盈+310] [✕] │ ← 点击平仓
│  [LU0 空 4613→4620 浮亏-350] [✕] │
├──────────────────┤
│ 扫描概览条（tradable/filtered）  │
├──────────────────┤
│ 品种列表                          │
│  [EB0 苯乙烯 -2.71% G4:5/5 B] [+]│ ← 点击"+"开仓
│  [LU0 LU燃油 -2.62% G4:5/5 C] [+]│
│  ...                              │
└──────────────────┘
```

**持仓卡片字段**：合约编号 / 品种名称 / 多空标签 / 入场价 → 现价 / 浮盈额+百分比 / 止损

**状态**：
- 空态：持仓看板折叠隐藏
- 加载态：骨架屏占位
- 错误态：Toast 提示

**交互说明**

| 元素 | 动作 | 响应 | 传参 | 备注 |
|------|------|------|------|------|
| 品种卡片右侧"+"按钮 | 点击 | 弹出 @sheet(open-position) | 品种代码+名称+方向+现价+key_levels | — |
| 开仓面板合约选择器 | 切换 | 拉取所选合约最新价 → 更新入场价/止损/目标 | 合约编号 | — |
| 持仓卡片 | 点击 | 弹出 @sheet(close-position) | 品种数据+入场信息 | — |
| 持仓看板折叠条 | 点击 | 展开/折叠持仓区域 | — | — |
| 下拉刷新 | 下拉 | 调 refresh + 刷新持仓+扫描 | — | — |
| 平仓确认"确认"按钮 | 点击 | 调 closeTrade → 刷新持仓列表 + auto-review | — | — |
| 开仓面板"确认"按钮 | 点击 | 调 createTrade → 刷新持仓列表 + auto-review | — | — |

**底部面板 open-position**：
- 标题："开仓 — {品种名}"
- 顶部：合约选择器（默认主力合约，下拉可选同品种其他月份，如 EB2508 / EB2509 / EB2510）
- 切换合约时：自动拉取该合约最新价格并更新入场价/止损/目标
- 字段：方向（多/空切换）、入场价（默认所选合约现价）、止损（默认主力 key_levels 偏移）、目标（默认主力 key_levels 偏移）、手数（默认 1）
- 操作：确认开仓、取消

**弹窗 close-position**：
- 标题："平仓确认 — {品种名}"
- 内容：入场价 / 现价 / 预估盈亏额+百分比 / 平仓理由（可选）
- 操作：确认平仓、取消
